# Car-price-prediction

A supervised machine learning project that predicts the resale price of used cars from their features, using Linear Regression and Lasso Regression.

Used car prices depend on factors like age, kilometres driven, fuel type and brand. This project cleans the data, builds features, and compares two regression models to estimate a car's price.
Target: selling price
Approach
Data cleaning: handled missing values
EDA: explored price distribution and how features relate to price
Feature engineering: [e.g. car age from year, encoding of fuel type, transmission and owner]
Modelling: trained Linear Regression and Lasso Regression on a train/test split
Evaluation: compared the models using R²
